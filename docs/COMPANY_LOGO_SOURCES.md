# Company brand artwork

The career directory uses locally hosted brand artwork. Original raster icons were collected from company websites and preserved in self-contained SVG image files. Additional monochrome brand marks come from Simple Icons (CC0); Adobe and Oracle artwork is from the gilbarbara/logos collection. Source URLs are recorded below and in each listing. Images load lazily, and missing or failed assets fall back to initials instead of displaying unrelated or invented logos. Parent-company marks can be shared for brand/business-unit listings.
